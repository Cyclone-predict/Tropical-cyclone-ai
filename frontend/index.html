Model Architecture

Lightweight CNN

A compact convolutional neural network designed for satellite image classification. Optimized for prototype inference speed while maintaining structural accuracy for cyclone pattern detection.

Input Data

Satellite Imagery

Accepts infrared and visible spectrum satellite images. The preprocessing pipeline normalizes and resizes input for CNN consumption via the HDF5 dataset loader.

Output

Cyclone / Intensity Inference

Returns cyclone detection status, pattern classification, predicted maximum wind speed (Vmax), confidence score, and trend analysis in JSON format.

Explainability

Grad-CAM Integration

Gradient-weighted Class Activation Mapping (Grad-CAM) highlights the spatial regions of the satellite image that most influenced the model's classification decision.

Dataset Information

Research data source and current prototype status.

PRIMARY RESEARCH DATASET

TCIR — Tropical Cyclone Intensity and Reanalysis

A comprehensive multi-spectral satellite imagery dataset for tropical cyclone analysis. TCIR provides the foundational data for training and evaluating cyclone detection and intensity estimation models.

IR1 — Infrared Channel 1

Primary infrared imagery capturing cloud-top temperatures for cyclone structure identification.

WV — Water Vapor

Water vapor channel imagery revealing upper-level moisture patterns and atmospheric circulation.

VIS — Visible Spectrum

Daytime visible imagery for high-resolution cloud feature analysis and eye detection.

PMW — Passive Microwave

Microwave satellite data penetrating cloud layers to reveal internal cyclone structure.

Intensity Metadata

Associated intensity estimates including maximum sustained wind speeds and central pressure values.

Historical Observations

Time-series cyclone tracks and observations from multiple ocean basins over decades.

CURRENT PROTOTYPE STATUS

Full TCIR training data has not been downloaded for the current prototype. The model has been validated using a structural validation asset, not the complete real TCIR dataset. Scientific validation will follow once full dataset training is complete.

About CycloneAI Labs

Smart India Hackathon 2026 — Problem Statement SIH26070

Project Overview

CycloneAI Labs is an AI-powered tropical cyclone intelligence platform designed as a decision-support technology for disaster management. The system leverages satellite imagery and deep learning to detect, classify, and analyze tropical cyclone patterns.

Theme

Disaster Management

Problem Statement

SIH26070 — Development of an intelligent system for tropical cyclone identification, classification, and intensity prediction using multi-source satellite data and advanced AI/ML techniques.

Technical Approach

  • Satellite imagery ingestion and preprocessing (IR, WV, VIS, PMW)
  • Lightweight CNN for cyclone pattern classification
  • Intensity estimation through deep learning regression
  • Grad-CAM integration for explainable AI
  • RESTful API backend for model serving
  • Responsive web frontend for real-time analysis

Current Status

This is a prototype demonstration. The AI pipeline has been structurally validated. Full training on the complete TCIR dataset is in progress. Results presented are from the prototype pipeline and should not be interpreted as scientifically validated meteorological predictions.
